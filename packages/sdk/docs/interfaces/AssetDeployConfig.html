    Marketplace category — must be one of the server's accepted values. ("bundles" also exists server-side but needs a bundle_items list this payload cannot express, so it is not offered here.)

    • "personas": the prompt comes from persona_config or from a persona file (the JSON sent as the file); the public description is never used as the prompt.
    • "motions": source is required (original or licensed_resale); library clips without resale rights cannot be listed.
