    • connectEmbed(frame: EmbedFrameLike, options?: EmbedBridgeOptions): EmbedBridge

      Connect to an embed framed in iframe. Create it right after setting the iframe's src, before the embed can post prometheus:ready.

      Parameters

      • frame: EmbedFrameLike
      • Optionaloptions: EmbedBridgeOptions

      Returns EmbedBridge

        frame.src = embedUrl + '?speak=' + encodeURIComponent('Hi there');
